 🏗️ Rozgar Chowk - Digital Labour Chowk
**Rozgar Chowk** ek open-source web application hai jo daily wage workers (skilled/unskilled) aur employers ke beech ke gap ko khatam karta hai. Yeh platform construction workers, painters, electricians aur plumbers ko direct kaam dhoondhne mein madad karta hai.
🌟 Key Features
* **Worker Directory**: Sabhi registered workers ki list unke skills aur experience ke saath dikhti hai.
* **Smart Search & Filter**: Users categories (जैसे Mason, Plumber) ya search bar ke zariye sahi worker turant dhoondh sakte hain.
* **Dual Registration**: Workers aur Employers dono ke liye alag-alag dynamic registration forms.
* **Data Persistence**: Browser ki `localStorage` ka use kiya gaya hai taki data refresh karne par bhi delete na ho.
* **Modern UI**: Glassmorphism design aur fully responsive layout jo mobile aur desktop dono par smoothly chalta hai.
   🛠️ Tech Stack Used
* **Frontend**: HTML5, CSS3 (Flexbox & Grid)
* **Interactivity**: Vanilla JavaScript (ES6+)
* **Icons**: Font Awesome
* **Fonts**: Google Fonts (Outfit)
 🚀 How to Run Local browser
1.  Is repository ko clone karein:
    ```bash
    git clone https://github.com/your-username/rozgar-chowk.git
    ```
2.  Project folder mein jayein.
3.  `index.html` file ko kisi bhi modern browser mein open karein.
